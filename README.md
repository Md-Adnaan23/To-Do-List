# 📝 To-Do List Web App

A simple, responsive, and developer-inspired **To-Do List web application** for managing daily tasks. Users can add, complete, edit, and delete tasks while their data is automatically saved in the browser.

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Edit existing tasks
- Delete tasks
- Save tasks using Local Storage
- Keyboard support
- Empty-state message
- Responsive design
- PWA support for offline usage

## 🛠️ Technologies Used

- **HTML** – Structure of the application
- **CSS** – Styling, responsive layout, and developer-inspired UI
- **JavaScript** – Task management and application logic
- **Local Storage** – Persistent task data
- **Service Worker** – Offline/PWA support
